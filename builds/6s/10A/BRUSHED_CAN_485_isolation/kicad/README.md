## How the sheet is built (read before editing)

The schematic is **label-wired, not drawn**: every pin that carries a net has
a global label placed on its connection point and every unused pin has a
no-connect flag there. There are no wires. This is deliberate — it removes
the hand-wiring Y-sign trap (`docs/solutions/architecture-patterns/schematic-pin-y-sign-when-hand-wiring.md`)
and makes the netlist the proof of connectivity. The consequence is that the
sheet is a netlist you can open in KiCad, not a diagram arranged for
reading; a human-arranged view is a follow-up (`TODO.md` 18.6).

`tools/gen_schematic.py` is the single source. It reads pin geometry from the
same `symbols/*.kicad_sym` files it embeds, so a regenerated symbol cannot
drift from the sheet. `python3 tools/gen_schematic.py --check` exits 0 only
when the committed sheet equals the generator output — run it before every
commit that touches either. **Do not edit the `.kicad_sch` by hand**; if
KiCad's GUI is used to rearrange it, port the change into the generator
or the next regeneration will drop it (the 6S/50A build's divergence trap).
